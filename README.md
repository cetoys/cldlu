# cldlu

Viral tarayıcı oyunları için tasarım skill'leri, fikir havuzu ve üretim gauntlet'i.

| Yol | Ne |
|---|---|
| `.claude/skills/viral-game-design/` | Paylaşılabilirlik odaklı oyun tasarımı skill'i (kanca, döngü, paylaşım motoru, presuasion, rubrik) |
| `.claude/skills/motion-graphics/` | Juice, zamanlama tabloları, 9:16 klip kompozisyonu, kart/replay animasyonu, kabul testleri |
| `games/00-fikirler-ve-puanlama.md` | 7 fikir, ağırlıklı puanlama, seçilen 3 oyun ve gerekçeler |
| `games/01-zam-kahini/CONCEPT.md` | Günlük fiyat tahmini bulmacası |
| `games/02-otobus/CONCEPT.md` | 3D ragdoll denge oyunu (Sepetçi boru hattı) |
| `games/03-lugat/CONCEPT.md` | Türkçe anlamsal kelime avı |
| `games/GAUNTLET.md` | Üretim loop protokolü (inşa + jüri saldırısı + kanıt) |
| `games/STATE.md` | Gauntlet durumu |

Loop'u başlatmak için:

```
/loop games/GAUNTLET.md dosyasını oku ve orada tarif edilen tek bir gauntlet
turu çalıştır. Tur bitince dur — sıradaki turu bekle.
```
